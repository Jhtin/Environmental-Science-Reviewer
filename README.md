# EcoQuest – Environmental Science Reviewer

A static, GitHub Pages-ready reviewer app based on the supplied Environmental Science reviewer.

## Included
- Chapter-by-chapter quick notes
- 100+ flashcards
- Multiple-choice quiz arena
- True/False speed round
- Matching game
- 25-question boss exam
- Population formula review and calculation questions
- XP, mastery, streak, and progress tracking with localStorage
- Responsive desktop/mobile layout
- Focus mode

## Run locally
Open `index.html` in a browser.

## Deploy to GitHub Pages
1. Create or choose a GitHub repository.
2. Upload `index.html`, `styles.css`, and `app.js` to the repository root.
3. In GitHub: Settings → Pages.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and `/ (root)`, then Save.

No build step is required.
